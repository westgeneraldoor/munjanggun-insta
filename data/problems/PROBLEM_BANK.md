# 문장군 Problem Bank — 문제 기반 콘텐츠 소스

> 목적: 제품이 아닌 **고객이 겪는 문제**에서 콘텐츠 주제를 출발시킨다.
> DEC-027 (2026-06-05) 신규 생성.
> 주제 자동 선정 엔진이 이 파일에서 문제를 탐색 → 훅 유형 선택 → 제품 연결 → 콘텐츠 생성.
> 최종 업데이트: 2026-06-05

---

## 사용법

1. **주제 기획 시:** 아래 카테고리에서 세부 상황 1개를 선택
2. **훅 유형 매칭:** AGENTS.md의 5가지 훅 유형(손실회피/실수방지/공감/비교/스토리) 중 가장 강한 것 선택
3. **품질 규칙 확인:** `data/problems/PROBLEM_QUALITY_RULES.json`에서 status, semantic_cluster, allowed_angle 확인
4. **제품 연결:** 해당 문제가 문장군 제품/서비스와 자연스럽게 연결되는지 확인
5. **Hook Score 채점:** 7점+ 확인. 단, Hook Score는 필요조건일 뿐 충분조건이 아님
6. **사용 표시:** 콘텐츠로 제작한 문제는 ✅ 표시, 콘텐츠 번호 기록

```
PROBLEM_BANK → PROBLEM_QUALITY_RULES → 브랜드/현실/중복 게이트 → Hook Score → 제작
```

## 보강 가이드

### 신규 문제 추가 기준
- 현장 데이터(AppSheet)에서 반복 등장하는 시공 사유
- DM 문의에서 반복되는 고객 고민
- 블로그 댓글/검색어에서 발견된 페인포인트
- 시즌별 이슈 (장마, 겨울, 이사 시즌)

### 번호 체계
- N: 소음(Noise)
- S: 냄새(Smell)
- C: 비용(Cost)
- F: 안전(saFety)
- A: 미관(Appearance)
- M: 습기/곰팡이(Moisture)
- W: 우풍/단열(Wind)
- D: 도어 기능/불량(Door)
- E: 중문 실측/설치 구조(Entry)

### 재활용 규칙
- ✅ 표시된 문제는 기본적으로 재사용하지 않는다.
- 재사용은 `PROBLEM_QUALITY_RULES.json`의 `reuse_allowed`가 true이고, 새 구매 이유/새 생활 상황/새 제품 연결이 모두 다를 때만 가능하다.
- `rejected`, `hold`, `duplicate_hold`, `season_hold` 상태 문제는 신규 MD 생성 금지다.
- `data/registry/INSTAGRAM_POSTING_REGISTRY.md`와 `semantic_cluster` 기준으로 의미 중복을 확인한다.
