# 폐기 문서: 문장군 이미지젠 캐러셀 OS

> 상태: 폐기됨.
> 현재 프로젝트 표준은 **캐러셀 MD/JSON 원고 제작 전용**이다.
> 이 문서는 더 이상 신규 세션의 제작 기준으로 사용하지 않는다.

## 폐기 사유

- Codex 이미지 생성 도구가 로컬 제품 이미지시트를 실제 첨부 레퍼런스로 사용하는 것을 보장할 수 없다.
- 프롬프트만으로 중문/도어 제품 구조를 재현하면 그럴듯한 가짜 이미지가 나올 위험이 높다.
- 프로젝트 범위를 MD 원고 제작으로 축소해 품질과 책임 경계를 명확히 한다.

## 현재 기준

```text
기준 문서 확인
  -> 문제은행/레지스트리 확인
  -> 후보 또는 기획안 제시
  -> 사용자 승인
  -> 캐러셀 MD/JSON 원고 생성
  -> npm run validate
  -> 완료 보고
```

## 금지

- 이미지 생성
- 이미지시트 생성
- 이미지 생성 프롬프트 작성
- 슬라이드별 최종 카드 프롬프트 작성
- 생성 이미지 QA
- 제품 레퍼런스 이미지를 프롬프트 설명으로 대체하는 행위

이미지 생성, 이미지시트, 카드 QA는 이 저장소의 작업 범위 밖이다.
