# 문장군 인스타그램 캐러셀 MD 구성 가이드

> 현행 표준: 캐러셀 MD/JSON 원고 제작 전용.
> v3 HTML / 모카 브라운 50:50 레이아웃은 `_archive/legacy-html-and-media-tools/`와 `content/published/html-legacy/`에만 보존한다.
> 이 문서는 최종 이미지 제작 지시서가 아니라, MD 원고의 슬라이드 구조와 문장 품질을 정하는 기준이다.

## 1. 원고 철학

문장군 캐러셀은 제품 카탈로그가 아니라 생활 문제 해결형 인스타 콘텐츠다.

핵심 원고 방향:

- 표지는 스크롤을 멈추게 하는 큰 훅
- 본문은 저장하고 싶은 진단, 비교, 체크리스트
- CTA는 문의 장벽을 낮추는 댓글/DM 유도
- 제품보다 생활 문제가 먼저 보이는 흐름

## 2. 산출물 기준

- 최종 산출물: 캐러셀 MD/JSON 원고
- 저장 위치: `content/source/carousel/NNN_주제명.md`
- 이미지 생성 프롬프트: 작성하지 않음
- 이미지시트: 생성하지 않음
- 최종 카드 이미지: 생성하지 않음
- HTML 신규 제작: 금지
- `caption_card`: 인스타 캡션/해시태그 원고 용도

## 3. 슬라이드 구조

기본 캐러셀은 아래 흐름을 따른다.

```text
cover -> point -> point -> compare/checklist -> checklist/point -> cta -> caption_card
```

MD 원고 작성 대상은 `cover`부터 `caption_card`까지다.

## 4. 원고 구성 규칙

- 각 슬라이드는 `type`, 핵심 문장, 보조 설명, tip 또는 CTA 역할이 분명해야 한다.
- `visual_intent`는 감정과 장면 의도를 적되 이미지 제작 프롬프트처럼 쓰지 않는다.
- 제품 구조보다 생활 문제가 먼저 읽혀야 한다.
- 저장형 슬라이드는 체크리스트, 비교, 진단 중 하나로 구성한다.
- `body`는 120자 이내를 권장한다.
- `tip`은 45자 이내를 권장한다.

금지:

- 이미지 생성 프롬프트를 작성하는 것
- 이미지시트나 카드 이미지 제작 단계로 넘어가는 것
- 제품 구조를 새로 상상해서 표현하는 것
- 근거 없는 시공 결과를 단정하는 것
- 광고 배너처럼 구매 압박을 주는 CTA

## 5. 표지 원고

목표: 1초 안에 멈추게 한다.

- `hook`은 가장 크게 읽혀야 한다.
- `badge`는 작게, `sub`는 보조 문장으로 둔다.
- 커버 텍스트는 가능하면 2문장 이하로 압축한다.

좋은 표지 조건:

- 누가 봐야 하는지 즉시 보임
- 어떤 문제가 있는지 즉시 보임
- 제품보다 생활 상황이 먼저 보임

## 6. 본문 원고

목표: 저장하고 싶게 만든다.

- `title` 중심으로 읽힌다.
- 도어, 중문, 문틀, 손잡이, 레일, 유리, 프레임은 실제 제품 설명을 벗어나지 않는다.
- compare는 두 선택지의 차이가 바로 보이게 쓴다.
- checklist는 3~4개 항목을 권장한다.

## 7. CTA 원고

목표: 문의하고 싶게 만든다.

- 행동은 하나만 남긴다. 예: 댓글로 `견적`.
- 댓글 키워드는 주제별로 달라도 CTA의 최종 목적지는 무료 방문실측 견적상담으로 명시한다.
- 신뢰 요소는 3개 이하로 압축한다.
- `무료`, `실측`, `직영`, `A/S`는 과하지 않게 사용한다.

## 8. 제품 표현 기준

MD 원고에서는 제품을 실제 서비스 범위 안에서만 표현한다.

대상:

- 3연동중문
- 원슬라이딩중문
- 스윙중문
- ABS도어의 문틀, 문짝, 손잡이, 캐치 구조

금지:

- 제품 구조를 새로 상상해서 단정하지 않는다.
- 중문을 방음, 안전, 단열의 완전 해결책처럼 말하지 않는다.
- 실제 이미지 결과물이 있어야만 검증 가능한 문장을 원고에 넣지 않는다.

## 9. MD QA 기준

완료 전 아래를 확인한다.

- JSON 코드블록 하나로 구성됐는가?
- 첫 슬라이드가 `cover`인가?
- CTA 슬라이드가 있는가?
- 마지막 슬라이드가 `caption_card`인가?
- 해시태그가 20~25개인가?
- `visual_intent`가 감정과 장면만 설명하는가?
- 이미지 생성 프롬프트나 이미지시트 지시가 섞이지 않았는가?
