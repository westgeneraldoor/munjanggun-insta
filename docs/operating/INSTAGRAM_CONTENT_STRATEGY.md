# 문장군 인스타그램 캐러셀 MD 전략

> 최종 업데이트: 2026-06-12  
> 현재 범위: 캐러셀 MD/JSON 원고 기획 전략  
> 제외 범위: 릴스, 숏폼, 이미지 생성, 카드 디자인, 발행 캘린더, 성과 자동화

## 1. 핵심 정체성

문장군은 인테리어 자랑 계정이 아니라 생활 문제 해결 계정이다.

캐러셀 원고는 제품명에서 출발하지 않는다. 고객이 겪는 불편, 불안, 손실 가능성에서 출발한다.

좋은 시작:

- 현관 소리 때문에 아이가 깬다
- 화장실 문 아래가 들뜨고 곰팡이가 반복된다
- 중문 견적을 받았는데 추가금이 불안하다
- 강아지가 복도 소리에 계속 짖는다
- 방문을 바꾸려는데 문틀까지 해야 할지 모르겠다

나쁜 시작:

- 3연동중문 장점
- ABS도어 소개
- 문장군 시공 안내
- 신제품 소개
- 할인/문의 유도

## 2. 콘텐츠 비중

신규 캐러셀 MD 기획 기준은 아래 비중을 따른다.

| 유형 | 비중 | 목적 |
|---|---:|---|
| 문제형 | 70% | 저장, 공유, 댓글/DM |
| 공감형 | 20% | 특정 상황 타깃 공감 |
| 권위형 | 10% | 체크 기준, 실측 기준, 제품 선택 기준 |

정보형은 단독으로 만들지 않는다. 반드시 문제 해결 맥락 안에 넣는다.

## 3. Hook Score 기준

캐러셀 제작 전 Hook Score를 채점한다.

| 점수 | 판정 |
|---:|---|
| 0~4 | 폐기 |
| 5~6 | 각도 변경 후 보류 |
| 7~10 | 제작 가능 |

가점 요소:

- 손실회피: 안 하면 돈, 시간, 안전, 생활 품질을 잃는가?
- 실수방지: 대부분 놓치는 체크포인트가 있는가?
- 공감: 특정 가족/생활 상황이 바로 보이는가?
- 비교: A/B 선택 고민을 줄여주는가?
- 스토리: 실제 사례처럼 읽히는 흐름이 있는가?

## 4. 기본 구조

문제 해결형 캐러셀 기본 흐름:

1. 문제 훅
2. 공감 상황
3. 원인 설명
4. 확인 기준
5. 문장군 서비스 연결
6. 댓글/무료 방문실측 견적상담 CTA
7. caption_card

권장 슬라이드 수는 6~8장이다. caption_card는 기본 포함한다.

## 5. 주제 선정 우선순위

1. `data/problems/PROBLEM_BANK.md`에 있는 미사용 문제
2. 최근 등록부에서 반복되지 않은 훅 유형
3. 저장 가치가 있는 체크리스트/비교/진단형 소재
4. 댓글 키워드가 자연스럽게 붙는 소재
5. 문장군 서비스 범위 안에서 정확히 설명할 수 있는 소재

중문/도어 제품 자체를 설명해야 할 때도 반드시 생활 문제와 연결한다.

예시:

- “3연동중문 장점” 대신 “현관이 좁은데 중문 포기해야 할까요?”
- “ABS도어 소개” 대신 “화장실 문 아래가 자꾸 썩는 이유”
- “스윙중문 소개” 대신 “복도 소리 때문에 현관을 한 번 더 막고 싶은 집”

## 6. CTA 전략

CTA는 하나만 둔다.

기본형:

```text
댓글로 '견적' 남겨주시면
무료 방문실측 견적상담 안내를 보내드릴게요.
```

상황별 키워드:

- 비용/추가금: `견적`
- 안전/아이/반려동물: `안전`
- 화장실문/방문교체: `문교체`
- 냄새/소음/우풍: `현관`

CTA는 구매 압박이 아니라 무료 방문실측 견적상담 진입 장벽을 낮추는 방식으로 쓴다.

## 7. 금지 전략

- 제품 카탈로그형 원고
- 근거 없는 가격/절감 수치
- “완벽 차단”, “100% 해결”, “무조건 가능”
- 경쟁사 비방
- AI 이미지 결과를 전제로 한 표현
- 레퍼런스 이미지시트 설명을 원고에 넣는 방식
- HTML/카드 제작 지시

## 8. 성과 해석 방식

이 프로젝트는 성과 기록 자동화를 하지 않는다. 다만 새 원고를 만들 때 등록부의 기존 반응 메모는 참고할 수 있다.

참고 기준:

- 저장 반응이 좋았던 주제는 체크리스트형으로 변주한다.
- 공유 반응이 좋았던 주제는 가족/배우자/반려동물 공감형으로 변주한다.
- DM 반응이 좋았던 주제는 CTA 문장을 재사용한다.
- 반응이 낮았던 정보형 주제는 문제형 훅으로 재설계한다.

## 9. 완료 기준

전략적으로 제작 가능한 캐러셀 MD는 아래 조건을 만족한다.

- Hook Score 7점 이상
- 문제에서 출발
- 문장군 서비스 범위 안에서 정확함
- CTA가 하나
- caption_card 포함
- 이미지 생성/HTML/카드 제작 지시 없음
- `npm run validate` Errors 0
